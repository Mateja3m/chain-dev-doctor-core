# Code of Conduct

## Our Standards

We are committed to a respectful, inclusive, and constructive community.

Examples of expected behavior:
- using welcoming and inclusive language
- giving and accepting constructive feedback
- focusing on what is best for the community

Unacceptable behavior includes harassment, abusive language, and personal attacks.

## Enforcement

Project maintainers are responsible for clarifying and enforcing community standards and may remove or edit contributions that violate this Code of Conduct.
