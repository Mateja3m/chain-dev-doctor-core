# Security Policy

## Supported Versions

This project is in active development. Security updates are applied to the latest minor release.

## Reporting a Vulnerability

Please report suspected vulnerabilities to milanmatejicdev@gmail.com

Do not report security vulnerabilities in public GitHub issues.

Include:
- impact summary
- steps to reproduce
- affected versions
- suggested mitigation if known

We will acknowledge reports promptly and work toward a fix and coordinated disclosure.
