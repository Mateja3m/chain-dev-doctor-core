# Contributing

## Development Setup

1. Install dependencies: `npm install`
2. Build workspace: `npm run build`
3. Run tests: `npm run test`
4. Run lint and typecheck: `npm run lint && npm run typecheck`

## Pull Request Expectations

- Keep changes focused and small.
- Add or update tests for behavioral changes.
- Preserve chain-agnostic boundaries in this repository.
- Ensure all checks pass before requesting review.

## Commit Style

Use clear, descriptive commit messages that explain intent and scope.
